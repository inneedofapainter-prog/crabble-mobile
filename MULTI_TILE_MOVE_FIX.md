# Multi-tile move fix

- Re-added safe multi-select board movement on top of the stable chat + Q-rule build.
- Tap board letters to select/highlight multiple tiles.
- Tap Word to select the whole word containing the selected tile.
- Tap an empty board square to move the selected group together while keeping its shape.
- Recall returns all selected board tiles to the rack.
- Online server accepts and validates grouped moves/recalls authoritatively.
- Existing chat, Q rule, profile/stats, Top 3 leaderboard, word policy, and rematch fixes are kept.
